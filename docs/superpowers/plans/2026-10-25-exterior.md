# Aba Exterior Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; implementar nesta sessão.

**Goal:** Separar a apuração do exterior em uma aba pública do B.U.

**Architecture:** Seção `exterior` e módulo `exterior.js`; catálogo estático de localidades do TSE com agrupamento geográfico do app. O módulo reutiliza `BUSecondRound.candidateCard` e consulta ZZ e o país/localidade selecionado.

**Tech Stack:** HTML, CSS, JavaScript sem dependências, Python e GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-25-exterior-design.md`

## Global Constraints

- Segundo turno, eleição 6258; nunca substituir por primeiro turno ou BR.
- Polling 5000 ms, sem recarga nem troca da área escolhida.
- Visitante pode abrir as duas abas públicas; lançamentos continuam fiscais.
- Total geral do exterior usa ZZ; país informa cobertura de localidades.

## Review Focus

- Dados antigos, de outra eleição ou área não substituem a parcial.
- Uma localidade indisponível não vira zero silenciosamente.
- Consulta lenta não sobrepõe requisições nem troca o filtro atual.
- Histórico, atalho e visitante alcançam Exterior.
- Atualização de cache não provoca recarga automática.
